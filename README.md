# DS-ROM: A non-intrusive snapshot regularization framework pairing Gaussian smoothing and non-linear deconvolution

![Tests](https://github.com/flabowski/POD-ROM-and-gaussian-convolution/actions/workflows/tests.yml/badge.svg)

This repository contains the code that was used to generate the figure for the article **Data regularization and deconvolution for non-intrusive reduced-order modeling of transport-dominated problems** by Florian Arbes, Øyvind Jensen and Kent-Andre Mardal (currently under revision).

Notebooks to generate the figures, see [notebooks](https://github.com/flabowski/POD-ROM-and-gaussian-convolution/tree/main/notebooks)

Code, see [source code](https://github.com/flabowski/POD-ROM-and-gaussian-convolution/tree/main/src/smooth_POD_ROM)

Install package in editable mode: `pip install -e .`
